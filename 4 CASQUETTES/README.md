# 4 CASQUETTES — Rôles permanents

Une **casquette** est une responsabilité qui n'a pas de fin prévue. Elle t'accompagne dans le temps sans deadline.

Exemples :
- Père, mère, compagnon, compagne
- Ton corps, ta santé
- Un rôle professionnel ongoing (dirigeant, consultant, artiste, salarié)
- Un engagement associatif régulier

## Structure d'une casquette

Chaque casquette est un dossier avec **la même structure PPAR que les projets** :

```
NomCasquette/
├── NomCasquette.md          ← Note de contexte (6 sections)
├── Suivi.md                 ← Kanban 5 colonnes
├── 1 Pourquoi/              ← Alignement local
├── 2 Plan/                  ← Planification, roadmap
├── 3 Action/                ← Exécution, suivi résultats
├── 4 Réflexion/             ← Bilans, apprentissages
└── 5 Ressources/            ← Images, infos, liens, fichiers
```

## Note de contexte — 6 sections

1. **Alignement** — le pourquoi de cette casquette, lien avec la vision
2. **Roadmap** — les grandes échéances ongoing (rituels, rendez-vous, engagements)
3. **Historique** — chronologie des grandes étapes
4. **Todo** — accomplissements + à venir
5. **Expérience** — insights, compétences acquises
6. **Réflexion / Idées au fil de l'eau** — idées émergentes captées à la volée

## Casquette vs Projet

| | Casquette | Projet |
|---|---|---|
| Durée | Ongoing (pas de fin) | Temporaire (deadline) |
| Structure | PPAR | PPAR |
| Exemples | Parent, dirigeant, santé | Livre à écrire, formation à suivre, déménagement |

Si tu doutes : "est-ce que cette activité peut se terminer un jour ?"
- Oui → Projet
- Non → Casquette

## Cadence de revue

Chaque casquette mérite une revue régulière (mensuelle ou trimestrielle) pour :
- Vérifier l'alignement (est-ce que je m'investis toujours dans le bon sens ?)
- Nettoyer le Suivi (déplacer les tâches, archiver ce qui est fait)
- Alimenter le fil de l'eau des idées
