# Outils — Références techniques transverses

Dépose ici les notes qui documentent les **outils** que tu utilises régulièrement à travers plusieurs projets/casquettes : logiciels, applications, méthodes techniques, configurations.

## Exemples de notes qui vont ici

- Un guide de configuration pour un outil particulier (VS Code, Obsidian plugin X, etc.)
- Une liste de raccourcis clavier qui te servent partout
- Un pattern technique réutilisable (ex : requête SQL récurrente, snippet git)
- Une infrastructure personnelle documentée (VPS, comptes, clés)

## Ce qui ne va pas ici

- Une configuration spécifique à UN projet → dans `3 PROJETS/MonProjet/5 Ressources/`
- Un outil dont tu documentes l'usage pour un rôle particulier → dans `4 CASQUETTES/MaCasquette/5 Ressources/`
- Une note de lecture ou une référence documentaire → à créer dans `5 RESSOURCES/` à plat
