## Comment créer une commande

Une commande = un skill Claude Code stocké dans `.claude/skills/<nom-commande>/SKILL.md`.

`/creer-commande` te guide conversationnellement :
1. Nommer la commande (kebab-case)
2. Décrire son rôle en une phrase
3. Formuler les étapes de son flux
4. Générer le fichier SKILL.md avec le bon frontmatter
5. Ajouter une entrée dans cette bibliothèque

Toute commande créée reste **locale à ton coffre**. Elle ne remonte nulle part automatiquement.
