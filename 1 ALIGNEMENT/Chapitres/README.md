# Chapitres — Cycle long (6 à 12 mois)

Un chapitre est une **période stratégique** de ta vie. Il porte une intention forte, un cadre, des engagements macro.

## Cycle

- **Durée typique** : 6 à 12 mois
- **Un seul chapitre actif à la fois** (frontmatter `status: active`)
- **Nommage** : `YYYY-MM - Nom du chapitre.md` (ex : `2026-08 - Fonder ma pratique du coaching.md`)

## Structure d'un chapitre

Chaque note de chapitre contient au minimum :

- **Frontmatter** : `status`, `période`, `chapitre`
- **Intention stratégique** — le pourquoi profond de ce chapitre
- **Triple ancrage** (optionnel) — les 3 dimensions structurantes (ex : opérationnel / créatif / systémique)
- **Objectifs macro** — les grandes lignes de ce que tu veux voir advenir
- **Contraintes** — ce qui pose le cadre (temporel, financier, relationnel)
- **Engagements personnels** — voyages, thérapie, relations, corps, épargne

## Cycle d'un chapitre

1. **Ouverture** — via `/nouveau-chapitre` (clôture le précédent + ouvre le nouveau)
2. **Vie du chapitre** — sert de vision de fond pour toutes les phases de vie qui s'y déploient
3. **Clôture** — bilan écrit, `status: completed`, ouverture du chapitre suivant

## Chapitre vs Phase de vie

Le chapitre est le **cadre long**. Les **phases de vie** (2-12 semaines) sont l'exécution opérationnelle dans ce cadre. Un chapitre peut contenir plusieurs phases successives.
