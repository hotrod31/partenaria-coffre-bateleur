# 0 INBOX — Sas de capture

Ce dossier est ton sas de capture. Il accueille tout ce que tu attrapes à la volée sans savoir encore où le ranger.

## Règle

Rien n'a vocation à rester ici. Traite l'inbox régulièrement (une à deux fois par semaine) avec la commande :

```
/trier-inbox
```

Ton partenaire IA te guidera pour router chaque item vers le bon dossier du coffre (projet, casquette, ressource, connaissance, archive).

## Ce qui va dans l'inbox

- Une idée fugace que tu veux capturer sans interrompre ton flow
- Un article, un lien, un extrait à traiter plus tard
- Un document reçu que tu veux intégrer sans savoir encore où
- Une note vocale transcrite

## Ce qui n'y va pas

- Un projet en cours (va directement dans `3 PROJETS/`)
- Une décision aboutie (va dans `2 CONNAISSANCES/`)
- Un livre lu ou une source utile (va dans `5 RESSOURCES/`)
